# 超级马里奥（SMB）RAM 地图

`smb_state.py` 读取的全部地址。**每个地址都带「怎么验证它对」的证据**——不是从网上抄的内存表，
是本机逐字节验过的。未确定的字段在 `read_state()` 返回里标 `None` 并进 `uncertain` 列表，绝不编数。

## 已定案地址

| 地址 | 字段 | 验证证据 |
|---|---|---|
| `0x07F8/0x07F9/0x07FA` | TIME（三位数字各占一字节） | 开局读 4,0,0；跑 240 帧后读 3,9,5 ⇒ 与画面 HUD 的 TIME 400→395 一致；并与视觉模型读出的 HUD（400/392/388/335/271）对齐过 |
| `0x075A` | lives 命数 | 开局 2；故意撞蘑菇兵死一次后读到 1（与 HUD ×2→×1 一致） |
| `0x07ED` | coins 金币 | **只验证到"0 与画面 ×00 一致"，≥1 未验证** |
| `0x0086` | 马里奥**世界 x 低字节**（256 回绕） | 按 RIGHT 递增/LEFT 递减（方向复核）；且 `(0x0086 − 0x071C) & 0xFF` 恒为 112（相机锁定后马里奥始终在屏幕 x=112）⇒ 是世界 x 低字节，不是屏幕 x |
| `0x071C` | 相机（关卡滚动左边缘） | 与 `0x0086` 联立后马里奥屏幕 x 恒为 112；把它当相机预测"关卡滚动"与画面一致 |
| `0x009F` | 马里奥垂直速度 vy | 跳跃时读到 251→252→…→0→…→4 的完整抛物线（与逐帧量的精灵高度同步）；站在地面上恒为 0 |
| `0x0200–0x023F` | 精灵 OAM（64 精灵 × 4 字节：y/tile/attr/x） | 敌人 = OAM 里"非马里奥的贴地精灵"，tile 可判种类（`0x70/0x71` = 蘑菇兵左右半）；与画面按颜色量出的实体列逐帧配对过 |
| `0x0756` | powerup 状态 | 见 `smb_state.py` 代码 |

## 读取要点

- **OAM 要读 PPU 那份**（`nes.ppu.spriteMem`）做标注真值；CPU 影子页 `$0200` 是游戏正在写的活数据，
  帧末读会撞上中间态（实测：帧 00465 影子里一只板栗仔都没有，画面里明明有两只在走）；
- **读满 256 字节 = 64 槽**——SMB 用满整页，敌人在高槽位；只读 16 槽会整只漏掉第二只板栗仔
  （栗子：帧 00465 两只板栗仔在槽 12-17 与 24-29）；
- `0xFC` 是空白填充 tile，不是生物像素。

## 未确定（诚实清单）

- 敌人槽表在 RAM 的哪一段（`0x06E0-0x06FF` 试过，不是）；
- 敌人的「存活/踩扁」状态字节；
- 场景结构（坑/障碍/?砖块）目前走**纯像素判据**（地砖 `#b15400` / 天空 `#8179ff` / 装饰绿分级），不依赖 RAM。

## 画面像素口径（与 RAM 互补）

| 常量 | 值 | 用途 |
|---|---|---|
| `SKY` | `#8179ff` | 坑判据 = 地面带里露出天空色 |
| `GROUND` | `#b15400` | 地砖主色（棕/浅桃/黑三层花纹交替 ⇒ 不能用"非地面色"判坑） |
| `MARIO_RED` | `#bc1900` | 小马里奥帽子/衣服，全屏唯一 ⇒ 画面里找马里奥的锚点 |
| 地面带 | y = 208–231 | 地砖带最上一行 208，232+ 是黑边 |
