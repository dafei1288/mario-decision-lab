# 实测数字（本机，2026-09-22/23）

全部为**本机自算/实测**；引用请标注。机器：CPU only（无 CUDA）。

## 1. 模型能力的三条硬测量（timing 座位，Laya 421M）

判据：不是「它不行、也不是我们没调好」——是模型自身的状态条件化。

| 测量 | 数字 |
|---|---|
| 四档 prompt 手段的「无危险窗口跳率」（目标 ≈0） | raw **1.00** → 真·2 候选 **0.78** → 强制脚手架 **0.60** → +硬约束 **0.54**（单调降但都到不了 <0.2） |
| 危险窗口跳率（目标 ≈1） | **1/1** ✓（该跳时它跳） |
| 两步问答的「危险判定准确率」（先问 yes/no 有没有危险，再选动作） | **0/20 = 0.00**（真值全为"无危险"，它 **20/20 报 yes**） |

⇒ 换问法只是换一种塌缩（raw 恒 jump / two_step Q1 恒 yes）⇒ 不是链路、不是措辞、不是候选集。

## 2. 分工架构（判断层 + 动作层）

配置：`--macro-brain script_guard --pulse-release 0 --jump-window 9999`
（判断层 = 检测器/规则，回归后常数 `pit 24 / obs 40 / lookahead 88`；模型只在安全集里挑）。

- **400 步 0 掉命**；TIME 401→330→…→0（旗杆段）→ 下一关 400 ✓
- 动作分布：small_jump 244 / sprint 156
- 对照：纯脚本大脑（`ref`）同座位 0 重开通关（TIME 400→338，余量很大）

## 3. 单点基准（自研确定性平台环境，97 决策点，真值 = BFS 最短解首动作）

| | Laya | NanoJev（0.6B 对照） |
|---|---|---|
| exact（tie 容忍） | 0.2474 ＝ 多数类基线 | 0.2474 ＝ 多数类基线 |
| ECE（10 分箱） | 0.027 | 0.0144 |
| 预测直方图 | `right_jump` 93 / `left` 4 | `right_jump` 97（全塌缩） |
| **错状态对照：选择翻转** | **6/97** | **0/97** |

⇒ 准确率一模一样、机理不同：Laya 读状态（喂错状态会翻盘 6%），NanoJev 决策层面状态盲。

## 4. 决策延迟（CPU，须标注是否空载）

- Laya ≈1.5 s/问（常驻模式，加载一次 12–35 s；权重 842MB）
- NanoJev ≈2–6 s/题（常驻，权重 2.385GB）
- ⚠ 同机并行时单例延迟翻 2–3 倍；同一份代码同一天均值 1387.8 / 2820.9 / 1001.7 ms——报延迟必须标「同机同时刻」

## 5. YOLO 检测器（detect/，详见 detect/README.md）

- 数据集：1200 帧全自动标注（真值 = PPU `spriteMem`，64 槽）；goomba 738 框、mario 946 框；train 1020 / val 180
- 训练：YOLOv8n CPU，imgsz=256，24.3 min（35 轮）
- 留出集：mAP50 **0.965** / mAP50-95 0.935；逐帧 IoU≥0.5：goomba F1 **0.996**、mario F1 0.950；逐帧一致率 95.6%；无真值帧误检 0/8
- 关键对照：真值从「CPU 影子页 16 槽」改「PPU 渲染那份 64 槽」⇒ mAP50 **0.656 → 0.990**（提升来自标注读法，不是调参）
- 带框录制：48 ms/帧 CPU 推理，平均 2.20 框/帧
