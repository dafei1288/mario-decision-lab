# ROM 说明

## 本目录自带

- **`nova.nes`** —— [Nova the Squirrel](https://github.com/NovaSquirrel/NovaTheSquirrel) v1.0.6a，
  开源 NES 平台游戏，**GPL-3.0**，可自由分发。开箱自检、协议验证、演示都用它。

## 不自带（版权）

**《超级马里奥兄弟》ROM 是任天堂版权内容，不在本工程内、勿提交、勿分发。**
本工程的分工架构/检测器实验是在本地用自备 ROM 验证的。你要复现：

1. 自行合法获得 `Super Mario Bros. (Japan, USA).nes`，放进本目录（文件名随意，命令行 `--rom` 指过去即可）；
2. `.gitignore` 已拦截 `*.nes`（`nova.nes` 例外放行），不会误提交；
3. 公开发布内容时：商业游戏画面用短片段 + 标注权利方；教学用途不免责。

## 换游戏

任何 NES ROM 丢进本目录换 `--rom` 即可，但注意：

- **开机配方每款游戏不同**（标题页→选关→开始的按键序列）：`--boot "START:6:60,A:4:60,A:4:90"`（键:按住帧:等待帧）；
- **RAM 地图每款游戏不同**：`smb_state.py` 的地址只对 SMB 有效；开源游戏（如 Nova）可去它的源码里查内存地图。
